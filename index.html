How it works

A transparent pipeline you can verify in the open-source code.

Detect

A content script finds recommendation cards as YouTube loads them.

Read

Only visible info: title, channel, video ID, view count.

Score

Compared against your local history with a weighted 0–100 model.

Explain

A short, hedged explanation appears beside the video.

35%Channel match
30%Topic match
20%Recent activity
10%Category match
5%Popularity
Honesty first: WhyFeed never claims to know YouTube's internal algorithm. Every explanation is an estimate from observable data.

Privacy is the product

Your watch history is yours. WhyFeed has no backend, so there is nothing to leak.

  • All analysis happens locally in your browser
  • Nothing is ever uploaded and there are no analytics
  • Only “storage” permission and youtube.com access
  • Clear all data any time from Settings

Install in four steps

Run the build once, then load it into Chrome in Developer mode.

cd whyfeed
npm install
npm run build
# Chrome → chrome://extensions → enable Developer mode
# → Load unpacked → select the "dist" folder
